# Ozon MCP — тщательный подбор товаров

[English](README.en.md)

Ozon MCP — локальный сервер [Model Context Protocol](https://modelcontextprotocol.io/) для исследования товаров на Ozon.ru. Версия 2.0.3 написана на Rust, использует `rmcp` 3.2 и нативный `agent-browser` 0.36.0. Сервер не меняет корзину, заказы, аккаунт или регион.

Статус: **development, проверен локально**. Оптимизированная сборка прошла 30 MCP-вызовов в шести категориях, возврат фотографий товара и отзыва, работу двух одновременных клиентов и восстановление после аварийного завершения брокера. Другие предложения продавцов (`offers`) пока не поддержаны наблюдаемым публичным источником. Ограничения и результаты проверки приведены в [описании поведения](docs/behavior.md#validation-on-2026-09-13).

## Инструменты

- `ozon_get_context` наблюдает общий контекст, регион и возможности;
- `ozon_search` ищет и уточняет выдачу;
- `ozon_get_products` пакетно читает карточки;
- `ozon_get_reviews` читает отзывы и наблюдаемые агрегаты;
- `ozon_get_images` возвращает проверенные изображения по сохранённым ссылкам;
- `ozon_list_research` и `ozon_get_research` читают локальный журнал;
- `ozon_append_research_note` добавляет идемпотентную заметку агента.

Цена с Ozon Картой остаётся отдельным наблюдаемым условием и не заменяется обычной ценой. Неизвестные и неполные данные возвращаются как `unknown`, `partial` или типизированная ошибка. Ссылки и курсоры привязаны к одному `researchId` и `contextId`; навигационные курсоры действуют 30 минут.

Для поиска, карточек и отзывов доступны представления `compact` (по умолчанию), `comparison` и совместимое полное `full`. Компактные ответы сохраняют статусы, неизвестные значения, время, контекст, предупреждения и `evidenceRefs`, а подробности доказательств можно локально получить через `ozon_get_research`. Отсутствующее из-за выбранного представления поле не означает наблюдаемое значение `unknown`. Повторный поиск поддерживает `repeatMode: delta`: строки не исчезают, а неизменённые данные раскрываются по `baselineProductRef` из неизменяемого снимка кандидата.

Наблюдаемый город не гарантирует различение двух аккаунтов в одном городе: такая смена может быть невидима серверу. Локальные продолжения секций карточки читают ограниченный сохранённый снимок с исходным timestamp.

Marketplace-вызовы только читают Ozon, но сохраняют локальные события и доказательства. Журнал хранится 30 дней, ограничен 512 МиБ и защищает используемое исследование от idle-очистки минимум на 10 минут. Заметки — локальные записи; один `operationId` с тем же содержимым возвращает прежний результат, а с другим — `CONFLICT`.

## Установка и запуск

Нужны Rust 1.95 и **точно** `agent-browser` 0.36.0.

```sh
git clone https://github.com/ibelyasov/ozon-mcp-server.git
cd ozon-mcp-server
cargo build --release --locked
cargo install agent-browser --version 0.36.0 --locked
agent-browser install
```

Обычный процесс — stdio frontend. Несколько frontend-процессов используют приватный локальный broker, один постоянный профиль браузера и один наблюдаемый контекст.

```json
{"mcpServers":{"ozon":{"command":"/absolute/path/ozon-mcp-server/target/release/ozon-mcp-server","env":{"OZON_AGENT_BROWSER_BIN":"/absolute/path/to/agent-browser","OZON_HEADLESS":"true","OZON_DATA_DIR":"/absolute/private/path/ozon-mcp"}}}}
```

`OZON_DATA_DIR` содержит приватный IPC и журнал и должен принадлежать текущему пользователю с правами `0700`. `OZON_USER_DATA_DIR` задаёт единственный постоянный профиль; `OZON_BROKER_SOCKET` при необходимости переопределяет сокет внутри data directory. Unix socket path должен помещаться в 103 байта. Поддерживаются macOS и Linux; Windows не поддерживается. По умолчанию `OZON_MCP_TEXT_MODE=compact`: полный успешный результат передаётся один раз в `structuredContent`, а текст содержит короткий указатель. Значение `json` дублирует полный JSON в тексте для старых text-only клиентов; другое значение останавливает запуск с ошибкой конфигурации.

Для ручного входа или выбора региона задайте `OZON_HEADLESS=false` **до запуска брокера**. Окно появится после `ozon_get_context` от MCP-клиента. Изменение переменной у нового frontend не переконфигурирует уже работающий брокер: сначала штатно завершите именно его или дождитесь автоматической остановки после 10 минут без запросов. При ручном запуске с `--broker` штатная остановка — Ctrl+C; SIGTERM также запускает очистку. После ручной настройки можно перезапустить тот же профиль в headless-режиме. Автоматического входа, смены региона и запасных профилей нет. Держите профиль и data directory вне репозитория.

## Как агент выполняет подбор

Агент фиксирует обязательные и желательные требования и бюджет, пробует разные формулировки, категории и доступные уточнения, изучает финалистов, отзывы и фотографии, пока новые проходы перестают улучшать выбор. Перед выводом он обновляет цену и доставку, рекомендует один основной вариант и не более двух альтернатив, объясняет отклонённых конкурентов, охват и неопределённость. Динамический каталог нельзя объявлять исчерпывающе просмотренным.

Подробности: [docs/behavior.md](docs/behavior.md). Контракты: [contracts/](contracts/README.md).

## Разработка

```sh
cargo +1.95.0 fmt --all -- --check
cargo +1.95.0 test --locked
cargo +1.95.0 clippy --locked --all-targets -- -D warnings
npm ci && npm run check:page && npm test
UV_CACHE_DIR=/tmp/ozon-contracts-uv uv run --offline --no-project --with 'jsonschema[format]==4.25.1' python scripts/validate-contracts.py
```

`rust/page.ts` компилируется в отслеживаемый `rust/page.js`; коммитьте их вместе. Офлайн-проверки не доказывают live-доступность Ozon. Подробности ограничений загрузки изображений, включая `OZON_IMAGE_DOH_FALLBACK=auto|off`, описаны в [поведении сервера](docs/behavior.md#image-dns-compatibility).
