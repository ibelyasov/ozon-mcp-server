# Ozon MCP — поиск товаров, цен и отзывов

[English](README.en.md)

Локальный сервер [Model Context Protocol](https://modelcontextprotocol.io/) только для чтения. Он даёт ИИ-ассистенту три инструмента для поиска товаров на **Ozon.ru**, чтения карточек и отзывов. Версия 0.4.0 написана на Rust, использует `rmcp` и нативный `agent-browser` 0.36.0. Node.js для сервера и драйвера не нужен.

Браузер по умолчанию работает без окна. Локальный профиль сохраняет cookies и регион между запусками; сервер не оформляет заказы, не меняет корзину и не требует Ozon Seller API или платного сервиса парсинга.

> **Текущий статус 0.4.0 (5 сентября 2026):** release-сборка Rust-сервера прошла живую проверку на macOS в headless-режиме. MCP запустил все три инструмента: поиск вернул два товара за 19,82 с, карточка SKU `947750106` — цену 6 859 ₽ и рейтинг 4,9 за 3,86 с, отзывы — две записи из 2 618 за 1,90 с. Повторная проверка описания подтвердила две картинки без отдельного текста. Весь stdio-сеанс завершился без ошибки за 25,78 с. Более ранние ответы HTTP 403 и временная ошибка драйвера остаются историческим напоминанием: текущий успех не гарантирует будущую доступность Ozon.

## Возможности

- `ozon_search` ищет до 36 товаров по запросу, диапазону цен и сортировке.
- `ozon_product_details` читает доступные цены, продавца, рейтинг, изображения, характеристики и описание по ссылке, SKU или slug.
- `ozon_product_reviews` читает до 30 доступных отзывов.

Каждый успешный вызов возвращает один и тот же валидный JSON как MCP `structuredContent` и текстовое содержимое. Неизвестные значения остаются `null`, а отсутствующие ожидаемые блоки отмечаются предупреждениями. Цены и наличие зависят от региона, сессии и условий оплаты.

## Установка 0.4.0

Нужны Rust 1.88+ и **точно** `agent-browser` 0.36.0. Сервер откажется запускаться с другой версией драйвера.

```sh
git clone https://github.com/ibelyasov/ozon-mcp-server.git
cd ozon-mcp-server
cargo build --release --locked
```

Установите нативный `agent-browser` 0.36.0 со страницы [официального релиза](https://github.com/vercel-labs/agent-browser/releases/tag/v0.36.0) либо соберите его через Cargo:

```sh
cargo install agent-browser --version 0.36.0 --locked
```

Затем отдельно установите управляемый браузером Chrome:

```sh
agent-browser install
```

Если вы хотите использовать уже установленный полный Chrome, укажите его существующий исполняемый файл через `OZON_BROWSER_EXECUTABLE`.

## Настройка MCP-клиента

Используйте абсолютный путь к собранному stdio-серверу. Абсолютный путь к закреплённому драйверу рекомендуется, особенно если MCP-клиент запускается с ограниченным `PATH`.

```json
{
  "mcpServers": {
    "ozon": {
      "command": "/absolute/path/ozon-mcp-server/target/release/ozon-mcp-server",
      "env": {
        "OZON_AGENT_BROWSER_BIN": "/absolute/path/to/agent-browser",
        "OZON_HEADLESS": "true"
      }
    }
  }
}
```

По умолчанию профиль находится в `~/.ozon-mcp-rust-profile`. После изменения конфигурации перезапустите или переподключите MCP.

### Видимый ручной сеанс

Для ручного входа или надёжного выбора региона задайте `OZON_HEADLESS=false`, переподключите MCP и вызовите инструмент. Проверьте вход и регион в открывшемся окне, затем остановите MCP и верните `OZON_HEADLESS=true`, сохранив тот же профиль. Видимый режим никогда не включается автоматически.

`OZON_CITY` пытается выбрать город через интерфейс Ozon. Если применить его не удаётся, запрос завершается ошибкой `REGION_SELECTION_FAILED`; сервер не выдаёт сохранённый регион за запрошенный. Даже успешная работа селекторов не доказывает выбранный регион, поэтому ручная проверка в постоянном профиле остаётся наиболее надёжным вариантом.

Храните профиль вне репозитория: он может содержать сессию аккаунта. Один профиль может принадлежать только одному процессу MCP одновременно.

## Разработка

Браузерный скрипт редактируется в `rust/page.ts` и компилируется TypeScript 7.0.2 в отслеживаемый Git файл `rust/page.js`. Rust встраивает готовый JavaScript, поэтому для сборки через Cargo и запуска сервера Node.js не нужен. Не редактируйте `page.js` вручную.

Для изменения скрипта нужен Node.js 22+ с npm:

```sh
npm ci
npm run build:page
npm run check:page
npm test
```

Команда `check:page` проверяет типы и соответствие `page.js` исходнику. Коммитьте оба файла вместе; CI повторяет проверку и офлайн-тесты браузерного скрипта.

```sh
cargo test --locked
```

В Rust-части девять обычных офлайн-тестов парсинга, проверки входных данных, границ результата и маршрутов fallback; все девять прошли. Отдельный игнорируемый по умолчанию тест с реальным Chromium проверяет отмену бесконечного JavaScript, закрытие частного браузера и успешный повторный запуск; он прошёл за 8,00 с. Ни один из этих тестов не зависит от Ozon и не подтверждает доступность маркетплейса. Команда и требования для opt-in теста приведены в [описании поведения](docs/behavior.md).
