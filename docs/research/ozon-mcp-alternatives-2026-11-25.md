# Альтернативы Ozon MCP и платные API

Срез на 2026-11-25. Это проверка опубликованных README, исходников и документации, а не запуск кандидатов. Цены и возможности облачных сервисов меняются; перед покупкой сверять страницы поставщиков.

## Текущий ориентир

Локальный Ozon MCP 3.0.0 — восемь инструментов для контекста, поиска, карточек, отзывов, изображений и локального журнала исследования. У него есть ссылки на сохранённые наблюдения, доказательства и заметки; он сохраняет неполноту/неизвестность, а секция предложений других продавцов сейчас `unsupported`. Браузер и профиль локальные, вход и смена региона автоматом не выполняются. Основание: [README](../../README.md), [контракт и поведение](../behavior.md), [ADR 0001](../adr/0001-v3-contract-and-journal.md).

Под «заменой» ниже понимается готовый MCP для чтения товаров покупателем. Совпадение количества функций не означает равной семантики наблюдений, полноты, безопасности или надёжности. Вендорские заявления о возможностях не подтверждены live-вызовами.

## Вывод для пилота

1. Среди открытых buyer MCP сначала проверять **SZhukovWork** как ближайшую ограниченную замену read-only каталогу; **Raleose** — если важнее Q&A, город и другие продавцы. Alexander-Zhukov требует отдельного решения по аккаунту и действиям заказа.
2. Для расширения охвата без поддержания собственного парсера попробовать **Apify**: он ближе всего к локальному проекту по городам, товарам, изображениям, отзывам, но потребует отдельно собирать данные, связывать запуск/результаты и учитывать оплату за город. **API.SH** — простой кандидат для бесплатного API/MCP пилота поиска, карточки и отзывов; покрытие доставки ограничено.
3. Ни один просмотренный кандидат публично не подтверждает локальный эквивалент provenance-журнала и исследования. Кандидатов не устанавливал, запросы к Ozon не запускал, деньги/аккаунты не использовал. Сначала сравнить одну и ту же выборку товарами и регионами и измерить полноту, свежесть, цены/доставку, ошибки и итоговую стоимость.

## Проверка и границы

Проверены README и исходные материалы репозиториев на зафиксированных коммитах, документация поставщиков и тарифные страницы. Даты коммитов и лицензии открытых репозиториев сверены с GitHub API на дату исследования. Реальный запуск/подключение MCP, login, live Ozon, корректность результатов, эксплуатационная надёжность, лицензии рыночных данных и доступность в конкретном регионе не проверялись. Изменчивые цены приведены как условия страниц на дату среза; коммерческие/юридические выводы требуют договора конкретного сервиса.

## Уточнение: только локальные покупательские MCP

Повторное сравнение исходников 2026-11-25, без запуска браузеров. Для подбора с подробными отзывами первым кандидатом стал **SZhukovWork**, а не Raleose. Это оценка реализованных возможностей, не доказательство лучшей работы на живом Ozon.

- **SZhukovWork** реализует предложения других продавцов, цены и наличие каждого варианта, сравнение до 20 SKU, распределение оценок, голоса полезности и ответы продавца (до 15 дополнительных запросов ответов за вызов). Отзывы имеют пагинацию и выбор SKU/линейки. Точность отдельного SKU-рейтинга условна и маркируется; не следует считать его всегда точным. Источники: [server.py](https://github.com/SZhukovWork/ozon-mcp/blob/414b3470ee6dd6f3197598b2c3c640d5d1601ef3/src/ozon_mcp/server.py#L256), [review parsing](https://github.com/SZhukovWork/ozon-mcp/blob/414b3470ee6dd6f3197598b2c3c640d5d1601ef3/src/ozon_mcp/parse.py#L877).
- **Raleose** действительно реализует Q&A, других продавцов, поиск/смену города и пакет 1–40 карточек. Однако чтение отзывов делает один запрос без параметра страницы: для глубокого анализа отзывов это регресс относительно нашего сервера. Изображение скачивается, но передаётся строкой Data URI внутри JSON, а не MCP image content. Camoufox-сессия не эквивалентна нашему постоянному авторизованному профилю. Источники: [ozon.js](https://github.com/Raleose/ozon-customer-mcp/blob/d6bc52e37b98f423d6f5c611a038778179db3f53/src/ozon.js#L674), [reviews](https://github.com/Raleose/ozon-customer-mcp/blob/d6bc52e37b98f423d6f5c611a038778179db3f53/src/ozon.js#L749), [browser](https://github.com/Raleose/ozon-customer-mcp/blob/d6bc52e37b98f423d6f5c611a038778179db3f53/python/browser_service.py#L41).
- **Наш v3:** публичная схема отзывов содержит aggregate rating/count, но не распределение звёзд, ответы продавца и голоса полезности. Варианты содержат идентичность и название, но не собственную цену/наличие; пакет карточек ограничен восемью. Преимущества: нативная выдача проверенных изображений агенту, постоянный общий профиль, контроль контекста и сохранение наблюдений. Основание: [схема отзывов](../../contracts/schemas/ozon_get_reviews.output.schema.json), [схема карточек](../../contracts/schemas/ozon_get_products.output.schema.json), [поведение](../behavior.md).

Вывод: по полезным покупателю данным SZhukovWork уже шире нашего; по всем свойствам сразу превосходство не установлено. Журнал исследования не является сам по себе основанием отвергать более функциональный инструмент. Перед заменой важнее проверить на одной выборке доступ, полноту отзывов/характеристик, правильность цен и города, а также доступность изображений для модели.
